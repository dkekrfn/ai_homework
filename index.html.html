01原理简介

多层感知机（MLP）是在单层线性模型（如 Y = A×颜色 + B×大小 + C）的基础上插入隐藏层， 并在每个神经元后接非线性激活函数（本实验用 sigmoid）的网络。它的训练是一个四步循环： 前向传播算出预测 → 损失函数量化预测与正确答案的差距 → 反向传播用链式法则把误差逐层回推、算出每个参数的梯度 → 梯度下降沿负梯度方向更新参数（W ← W − η×梯度），重复直至损失收敛。

为什么必须加隐藏层？ 单层模型只能画一条直线，而 XOR 的四个样本在坐标系中呈对角线交叉，任何直线都无法分开（线性不可分）。 隐藏层的作用是把原始输入空间"折叠"成新的表示空间，使原本线性不可分的样本变得线性可分—— 本实验用可视化验证了这一点。

02实现

网络结构为 2 → 2 → 1（两个隐藏神经元），参数手动定义并借助 PyTorch 的自动求导机制训练， 以保证对训练循环中每一步的理解都落在公式本身。核心代码两段：

前向传播与损失

h = torch.sigmoid(X @ W1 + b1)   # 隐藏层：2个神经元的输出
p = torch.sigmoid(h @ W2 + b2)   # 输出：概率(0~1)
loss = -(y*torch.log(p) + (1-y)*torch.log(1-p)).mean()   # 二元交叉熵

反向传播与梯度下降

loss.backward()                  # 反向传播：自动计算所有参数的梯度
with torch.no_grad():
    W1 -= lr * W1.grad           # 梯度下降：沿负梯度方向更新
    b1 -= lr * b1.grad
    W2 -= lr * W2.grad
    b2 -= lr * b2.grad
W1.grad.zero_(); b1.grad.zero_() # 梯度清零，防止跨轮累加
W2.grad.zero_(); b2.grad.zero_()

04实验二：学习率的四重人格

固定网络结构、数据与随机种子，仅改变学习率 η（0.01 / 0.1 / 1.0 / 10.0）各训练 2000 轮， 用控制变量法观察学习率对训练过程的影响。

各档最终结果对照（实测）：

学习率最终损失判对数人格类型
0.010.69223 / 4 *沉睡型：步长不足，未开始学习
0.10.46953 / 4稳健慢跑型：方向正确，轮数不够
1.00.01034 / 4甜点型：速度与稳定的平衡
10.00.46882 / 4暴走被困型：震荡后陷入平坦区
一个反直觉的发现：lr=0.01 判对 3/4，看似不错，实则损失卡在 ln2≈0.693（纯随机猜测的水平）—— 它把所有样本都输出 ≈0.5，因判定阈值 ≥0.5 记为 1，输出 (0,1,1,1) 恰好蒙对 3 个。 这说明判对数可能掩盖模型"根本没学"的事实，损失值才是更诚实的指标； 反之 lr=10.0 判对 2/4、损失 0.47，则暴露了它确实把部分样本学反了。

05结论与反思

结论：学习率的选择是"速度 vs 稳定"的权衡——太小则浪费算力原地不动， 太大则剧烈震荡后陷入坏区域，最优值存在但需实验寻找。现代优化器（如 Adam） 通过为每个参数自适应调节步长来缓解这一问题。

反思：实验前我预测 lr=10 会因步长过大而发散（损失变 nan）， 实测却是"剧烈震荡后被困在 0.47 的平台"——真实系统比预期更微妙。 这提醒我：做实验要记录实际发生了什么，而不是确认自己希望发生的。
